# 🏫 TruePresence
> Autonomous Multi-Vector Verification Engine against Ghost Schools  
*Built for Sukkur IBA IET TechFest Hackathon 2026 (Khairpur District Problem)*

## Features
- **Blind Route Dispatch:** Unannounced geofence reveals target within 500m.
- **Direct Fuel Allowance:** Mobile wallet transfer eliminates dependency on local host[cite: 1].
- **3-Vector Telemetry:** Cross-validates rosters against food supplies and SIM density.
- **Cluster Budget Protection:** Reallocates ghost school budget into student transport[cite: 1].
